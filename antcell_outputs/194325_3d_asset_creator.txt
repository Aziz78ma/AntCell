**Project 1: The Enchanted Forest**

* **Characters:**
	+ Rosie (rabbit): Age 4-6 years old. Design a cute and curious rabbit with big eyes, fluffy fur, and a twitching nose. Use Blender to create a high-poly model with around 10,000 polygons.
	+ Tree spirits: Create multiple tree spirit characters with different designs, each with unique personalities and expressions. Utilize Unreal Engine for dynamic lighting and animation.
* **Environments:**
	+ Enchanted forest: Design a whimsical environment with towering trees, twinkling lights, and vibrant flowers. Use Blender to create high-poly models with around 50,000 polygons.
	+ Forest floor: Create a detailed forest floor with intricate textures, rocks, and foliage. Utilize Unreal Engine for dynamic lighting and animation.
* **Props:**
	+ Magic crystal: Design an ancient magic crystal that glows softly in the forest. Use Blender to create a high-poly model with around 5,000 polygons.
	+ Leaves and flowers: Create realistic leaves and flowers that sway gently in the wind. Utilize Unreal Engine for dynamic animation and lighting.
* **Rigging:**
	+ Rosie: Create a rig for Rosie using Blender's built-in rigging tools or third-party plugins like Rigify. Ensure she has a full range of motion, including facial expressions and body language.
	+ Tree spirits: Develop rigs for each tree spirit character, allowing them to animate and move independently.

**Technical Requirements:**

* Each project will utilize either Blender or Unreal Engine as the primary software for 3D modeling, animation, and lighting.
* Adobe After Effects will be used for compositing and visual effects.
* Rigging will be done using Blender's built-in rigging tools or third-party plugins like Rigify.
* High-poly models should have around 5,000-10,000 polygons, depending on the complexity of the design.
